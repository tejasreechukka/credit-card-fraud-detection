Credit Card Fraud Detection: Manual vs AI-Assisted Analysis

Project Overview

This MSc Data Science project investigates credit card fraud detection using a highly imbalanced transaction dataset. It compares a manually conducted data science workflow with an AI-assisted workflow.

Research Question

How effectively can machine learning identify fraudulent transactions, and how does AI assistance affect the quality, reliability, and efficiency of the analysis?

Objectives

- Explore and audit the transaction dataset.
- Perform independent exploratory data analysis.
- Develop baseline and advanced classification models.
- Evaluate models using appropriate fraud detection metrics.
- Compare AI recommendations with independently verified results.
- Document errors, limitations, ethical considerations, and conclusions.

Technology Stack

Python, pandas, NumPy, Matplotlib, Seaborn, scikit-learn, Jupyter, Git, and GitHub.

Repository Structure

- "data/": dataset instructions and local data folders.
- "docs/": research documentation and experiment logs.
- "notebooks/": exploratory analysis and model experiments.
- "src/": reusable Python code.
- "tests/": validation tests.
- "reports/": final report and selected figures.
- "outputs/": evaluation results and model documentation.

Dataset

The project will use the public Kaggle Credit Card Fraud Detection dataset. The dataset will remain local and will not be committed to Git.

Project Status

Day 1: Initial repository, documentation, and environment setup.

Reproducibility

Dependency versions, data preparation, experiment settings, and evaluation methods will be documented throughout the project.

AI Use

AI tools will be used as assistants for research, coding, and review. Their suggestions will be recorded and independently verified.

Limitations

The dataset contains historical transactions and anonymised transformed features. Experimental results do not guarantee performance in a real-world fraud detection system.
